# CSCE547-MinorProject2

To Run:

1: Open TaskScheduler/TaskScheduler.sln or TaskScheduler.csproj to load both the DataLayer and the TaskScheduler projects.

2: Build and fill an MSSQL database using the scripts in DataLayer/DatabaseScripts.

3: In the App.Config file for both projects replace the connection string fields in <> with the corresponding values for your database.

4: Run.
